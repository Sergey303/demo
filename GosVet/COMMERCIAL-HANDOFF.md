# GosVet — передача на Engineering

Публиковать как интерактивный инженерный пример, а не как готовую
ветеринарную медицинскую систему. Исходники: Sergey303/demo, GosVet/.

## Карточка на Engineering

**Рабочее место специалиста со сложным бизнес-процессом и помощником**

Интерактивный пример на React: поиск пациента, история приёмов, контекстные
подсказки в ходе заполнения записи, уточняющие вопросы, проверка полноты,
коррекция данных и раздельные статусы внешней отправки.
Показывает подход к проектированию рабочих мест специалистов, сложных форм,
управлению состоянием и интеграционным сценариям.

Основная кнопка: «Попробовать интерактивное демо» → /demos/gosvet/
Дополнительная: «Открыть заполненный пример» →
/demos/gosvet/app.html#/appointment/demo-003

Рядом разместить CTA услуг Engineering: обсудить аналогичный рабочий
процесс заказчика. Не вести посетителя только на GitHub.
Указать: учебные данные, подсказки имитируются локальными правилами,
ВЕТИС не подключён, клиническая валидация не проводилась.

## Публикация

Собрать из корня репозитория:
    python public-demos/build.py --out /tmp/commercial-demos-release
    cd public-demos
    npm run smoke -- /tmp/commercial-demos-release

Разместить каталог под /demos/ как единый статический пакет.
Не публиковать корень репозитория. Проверить HTTPS и прямые ссылки.
Если базовый путь отличается, адаптировать ссылки Engineering.
Сценарий на странице демо короткий; технические сценарии G01–G23
хранятся отдельно. Скриншоты и короткое видео можно добавить после
подключения; не блокировать ими выпуск. Использовать только реальные
снимки учебного интерфейса без личных данных.
