# Архитектура и готовность

## Поток
Клиент → DNS / маршрутизация BGP+Anycast (провайдер или симуляция) → edge-защита L3/L4/L7 → origin API → метрики.
AI-анализ **не находится в критическом пути по умолчанию**; см. соседний EdgeAI.

## Общие измерения
- Доля пропущенных корректных запросов и false positives (на размеченном наборе).
- Доля отклонённых вредоносных запросов и false negatives.
- p50/p95/p99 задержки, нагрузка origin, количество 403/429/5xx.
- Восстановление после отказа точки, поведение существующих соединений.
- Стоимость и операционная сложность (позднее, с подтверждёнными данными).

## Критерии готовности v1
- [ ] Описаны и размечены одинаковые синтетические сценарии у всех реализаций.
- [ ] Локальный ограниченный генератор нагрузки и воспроизводимые метрики.
- [ ] Cloudflare: WAF, rate limiting и Worker в staging; подтверждены логи и откат.
- [ ] EdgeЦентр: подтверждена доступность требуемых сервисов и способ настройки в выбранном тарифе.
- [ ] Отдельно показаны реальные свойства провайдера и имитации.
- [ ] Отказ origin, edge-узла, ложные блокировки, stale policy и деградация API проверены.
